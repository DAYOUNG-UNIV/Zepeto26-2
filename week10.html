반 전체

왜 유니티 빌드잇 템플릿으로 다시 짓나

유니티 안에서 빌드잇 오브젝트를 골라 놓는 도구입니다. 받는 파일 이름은 ZEPETO Build it Unity Plug-in.

1각자 지은 구역을 한 맵에 합칠 수 있습니다앱 맵은 만든 사람 계정에만 저장되고, 여러 맵을 하나로 합칠 수 없습니다. 유니티에서는 구역을 묶어 파일로 넘깁니다.
2흰 큐브로 둔 것을 채울 수 있습니다말을 거는 NPC, 체크포인트, 움직이는 발판, 팝업, 내 음악 파일, 하늘 색과 빛까지 오브젝트로 들어 있습니다.
3앱에서 익힌 것이 그대로입니다같은 오브젝트를 영어로 찾아 놓고, 위치 · 회전 · 크기를 숫자로 맞추고, 스폰에 서서 걸어 봅니다.
대신 준비가 더 듭니다
  • 유니티 2022.3.34f1 설치와 저장 공간
  • 더 높은 컴퓨터 사양
  • 제페토 정식 계정
  • 영어로만 된 폴더 경로
  • 지금은 가로 화면만
  • 올리는 파일은 1GB 미만

지어 온 구역은 스케치였습니다

앱 맵을 유니티로 옮기는 방법은 안내되어 있지 않습니다. 큰 것만 놓은 스케치라 다시 놓는 데 오래 걸리지 않습니다. 오늘 고친 평면도대로 다시 놓습니다.

과제에서 많이 쓸 것 · 어디서 바꾸나

Hierarchy나 Scene에서 고르면 Inspector에 설정 칸이 나옵니다. 이름은 가이드 기준입니다.

spawnSpawnPoint없으면 0, 0, 0에서, 여러 개면 그중 하나에서 무작위로. 대표 구역에만 하나
하늘과 빛Zepeto Scene Settings하늘 세 가지 색과 빛의 방향 · 세기
움직임Manager걷기 · 달리기 · 점프 · 이중 점프 · 중력. 편집 상태에서 바꾸기
말풍선 NPCHas Speech BubbleSpeech Bubble Text에 한 줄. 편집 화면에는 안 보이고 ③에서만
대화 NPCDialogue HelperZEPETO 메뉴에서 열고 Create New → 대사 → NPC 끌어 넣기 → Export. 고칠 때마다 다시 Export
첫 화면 팝업PopupBackground Image · Message · Button Title. 땅이 아니라 화면 위에 뜸
순간 이동Teleport자식 destination을 옮긴 자리로 도착
배경 음악BGMAudioClip에 .mp3 · .wav. 장면에 하나만

구역 담당이 테스트하려고 놓은 spawn은 묶음 밖에 둡니다. 묶음 밖에 있으면 넘기는 파일에 들어가지 않습니다.

바꿨으면 ③으로 확인. NPC와 팝업은 편집 화면에 보이지 않는 게 정상입니다.
