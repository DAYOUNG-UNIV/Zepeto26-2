각자

시작하자마자 · 유니티부터 켜 두기

과제에서 해 본 것을 강의실 컴퓨터에서 한 번 더 합니다. 열리는 데 오래 걸려서 먼저 켜 두고 보드로 갑니다.

순서

  1. 1유니티 허브 열기 · Projects 목록에 zepeto_buildit_unity_plugin(또는 바꾼 이름)이 있으면 눌러서 엽니다.
  2. 2목록에 없으면 · 가져온 압축을 C:\zepeto처럼 영어로만 된 경로에 풀고, 허브 Add › Add project from disk로 안에 Assets가 보이는 폴더를 고릅니다.
  3. 3열리는 동안 · 처음 열기는 오래 걸립니다. 기다리지 말고 보드로 갑니다.
  4. 4열리면 · Project 창 › Assets › WorldScene 더블 클릭 → ▼ › Login → Start Multiplay Server 초록 → ▶
과제를 아직 못 했으면

오늘은 옆자리 조원 컴퓨터를 같이 봅니다. 묶음 연습은 둘이 한 컴퓨터로 해도 됩니다. 막힌 곳은 수업이 끝나고 강사와 같이 봅니다.

월드 연결(Link)은

조원은 과제에서 만든 내 월드 ID를 그대로 써도 됩니다. 올리기는 대표 계정의 조 월드 ID 하나로만 합니다.

파일은 내 것으로

강의실 컴퓨터에 남긴 것은 다음 시간에 없을 수 있습니다. 만든 묶음은 USB나 클라우드에 챙깁니다.

조별⑯ 우리 월드 규칙

한 월드로 보이게 하는 규칙 여덟

넷이 따로 지어도 한 사람이 지은 것처럼 보이려면, 짓기 전에 정해 둡니다. 칸마다 한 줄.

정하는 법

한 사람씩 후보를 붙이고, 칸마다 점 하나씩 투표. 9주차 한 문장과 레퍼런스에 맞는 쪽으로.

규칙은 바뀌어도 됩니다. 바꿀 때는 보드에서 고치고 조원에게 알립니다. 남이 만든 모델 · 텍스처나 AI로 만든 것은 ⑬에 출처를 적습니다.
조별⑪ 나눠 맡기

구역 하나 = 묶음 하나 = 한 사람

좌표 읽는 법

묶음 이름

T조번호_구역_이름, 영어와 숫자만. 오늘 연습할 묶음도 이 이름으로 만듭니다.

하나만 있어야 하는 것은 대표 장면에 둡니다. 스폰, 배경 음악, 하늘 설정이 그렇습니다.

물건 셋짜리 작은 묶음으로 한 바퀴 돌아 봅니다. 큰 구역을 처음부터 보내면 어디서 틀렸는지 찾기 어렵습니다.
